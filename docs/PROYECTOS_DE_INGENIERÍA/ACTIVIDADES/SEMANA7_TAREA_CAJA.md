# SEMANA 7 TAREA CAJA DE ACERO NEGRO CALIBRE 24

## Karen

Para esta tarea seguí un proceso manual de medición, corte, doblado y ensamble. Primero tomé las medidas necesarias y tracé en la lámina las tres partes principales: el contorno de la caja, la base y la tapa (incluyendo el diseño para la manija). Una vez marcado todo el diseño sobre la lámina, procedí a cortar el contorno con las herramientas adecuadas (tijeras o cortadora de metal).

<div align="center">
<img src="../../assets/imgs/S71.jpg" alt="Resultado" width="200">
</div>

Después del corte, empecé a doblar los bordes a 180°, para así eliminar el filo del metal y evitar que las orillas quedaran filosas. Posteriormente realicé los dobleces principales para formar cada pieza: el cuerpo de la caja, la base y la tapa. Cada doblez se hizo cuidando los ángulos para que el ensamble final quedara alineado.

En las zonas donde era necesario unir piezas, utilicé la soldadora por puntos para fijarlas de manera segura sin deformar la lámina. Con este proceso, finalmente uní la base con el contorno y después coloqué la tapa con su manija en la parte superior.

<div align="center">
<img src="../../assets/imgs/S72.jpg" alt="Resultado" width="200">
</div>

Para terminar, instalé una bisagra que permite abrir y cerrar la caja, completando así el funcionamiento del elemento. El resultado fue una caja metálica resistente, funcional y fabricada completamente desde cero.
